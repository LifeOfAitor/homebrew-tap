# LifeOfAitor's Homebrew tap

Homebrew recipes for my tools.

```sh
brew install LifeOfAitor/tap/txoko
```

| Tool | What it is |
|---|---|
| [txoko](https://github.com/LifeOfAitor/txoko) | A cozy corner for your terminal that grows as you work 🌱 |

The casks in `Casks/` are generated automatically by [GoReleaser](https://goreleaser.com) on every release, so please don't edit them by hand.
